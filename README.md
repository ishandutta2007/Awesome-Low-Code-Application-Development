# Awesome-Low-Code-Application-Development

# Top Low-Code Application Development Platforms Ecosystem
**Curated List of SaaS Products & Open-Source GitHub Projects**
*Focused on Visual App Builders, Internal Tools, Citizen Development, Drag-and-Drop Interfaces & Rapid Application Delivery*
**Last updated: October 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Low-Code Application Development**. These tools enable faster creation of web and mobile applications through visual builders, pre-built components, and minimal hand-coding—serving both professional developers and citizen developers.

**Examples** include Microsoft Power Apps, OutSystems, Mendix, Appian, Quickbase, Retool, Betty Blocks, Bubble, Glide, and Zoho Creator (the category leaders).

**Open-source emphasis**: Enterprise low-code platforms remain largely commercial, but a strong open-source movement exists for internal tools and self-hosted builders. **Appsmith**, **ToolJet**, **Budibase**, **NocoBase**, and similar projects provide capable alternatives. This section is heavily expanded.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms
- **[Microsoft Power Apps](https://powerapps.microsoft.com/)**  
  Microsoft’s low-code platform tightly integrated with Microsoft 365, Dataverse, and Azure for building internal business applications and workflows.

- **[OutSystems](https://www.outsystems.com/)**  
  Enterprise low-code platform focused on full-stack application development, scalability, governance, and complex business systems.

- **[Mendix](https://www.mendix.com/)**  
  Siemens-owned low-code platform emphasizing rapid development, multi-cloud deployment, and collaboration between business and IT.

- **[Appian](https://appian.com/)**  
  Low-code automation platform strong in process orchestration, case management, and AI-assisted application development.

- **[Quickbase](https://www.quickbase.com/)**  
  No-code/low-code platform oriented toward business users for building custom workflow and data-driven applications.

- **[Retool](https://retool.com/)**  
  Developer-focused low-code platform specialized in building internal tools, admin panels, and dashboards connected to existing data sources.

- **[Betty Blocks](https://www.bettyblocks.com/)**  
  No-code platform designed for citizen developers and enterprises to create scalable applications with strong governance.

- **[Bubble](https://bubble.io/)**  
  Popular no-code platform for building full-featured web applications and MVPs without traditional coding.

- **[Glide](https://www.glideapps.com/)**  
  No-code platform that turns spreadsheets into polished mobile and web apps quickly.

- **[Zoho Creator](https://www.zoho.com/creator/)**  
  Zoho’s low-code application development platform for building custom business apps with forms, workflows, and integrations.

## Open-Source GitHub Projects
- **[Appsmith](https://github.com/appsmithorg/appsmith)**  
  Leading open-source low-code platform (Apache-2.0) for building internal tools, admin panels, and dashboards with a strong widget library and self-hosting support.

- **[ToolJet](https://github.com/ToolJet/ToolJet)**  
  Open-source low-code platform for building internal tools with extensive integrations, JavaScript/Python support, and AI-assisted features.

- **[Budibase](https://github.com/Budibase/budibase)**  
  Open-source low-code platform focused on rapidly turning databases into working internal applications and workflows.

- **[NocoBase](https://github.com/nocobase/nocobase)**  
  Extensible open-source no-code/low-code platform with a data-model-first approach and plugin architecture.

- **[ILLA Builder](https://github.com/illacloud/illa-builder)**  
  Open-source low-code tool for building internal tools with a modern UI and developer-friendly extensibility.

- **[Directus](https://github.com/directus/directus)**  
  Open-source data platform that can serve as a headless backend and admin app generator for custom applications.

- **[Baserow](https://github.com/bram2w/baserow)**  
  Open-source no-code database and application builder positioned as an Airtable alternative.

- **[Documentation and Appsmith / ToolJet / Budibase deployment guides](https://docs.appsmith.com/)**  
  Resources for self-hosting, connecting data sources, and building production internal tools.

- **[Self-hosted internal tool frameworks and admin generators](https://github.com/)**  
  Community projects that generate CRUD interfaces and admin panels from existing databases or APIs.

- **[Open-source workflow and form builders](https://github.com/)**  
  Complementary tools often used alongside low-code platforms for process automation and data collection.

### Additional Strong Open-Source Options
- Choosing **Appsmith** for mature, Apache-licensed internal tool development.
- Using **ToolJet** when broad integrations and AI-assisted building are priorities.
- Adopting **Budibase** for fast database-to-app workflows.
- Exploring **NocoBase** for data-model-centric, extensible applications.
- Accepting that enterprise-grade governance, complex process automation, and large-scale citizen-development platforms (OutSystems, Mendix, Appian, Power Apps, etc.) still favor commercial solutions.
- Focusing open-source efforts on internal tools, data-driven apps, and freedom from vendor lock-in.

**Frameworks for building custom systems**: Self-host Appsmith, ToolJet, or Budibase → connect to existing databases and APIs → build admin panels and internal apps visually → extend with custom JavaScript/Python where needed. Suitable for engineering teams and organizations that want control over data and hosting. Many enterprises still choose commercial low-code platforms for support, compliance, and scale.
